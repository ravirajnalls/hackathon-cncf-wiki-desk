# Related runtimes

These projects aren't CNCF projects, but CNCF projects such as
[Kubernetes Agent Sandbox](../projects/kubernetes/agent-sandbox.md) build on them for isolation:

- [gVisor](gvisor-for-ai-agent-isolation.md): a user-space application kernel.
- [Kata Containers](kata-containers-for-ai-agents.md): a lightweight VM per sandbox.
- [Firecracker](firecracker-microvms-for-agent-sandboxes.md): a minimal microVM monitor.
